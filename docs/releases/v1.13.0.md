# FireLens v1.13.0

本版新增啟動重複掃描準備提醒，以及大圖預覽的滑鼠定點滾輪縮放與左鍵按住平移；已通過自動化、Chromium 操作與 Windows 封裝／更新器驗證。

## 新增與改善

- 啟動照片索引掃描完成後，若仍有本機照片缺少最新的重複檢查指紋，會先提醒準備掃描，避免等貼上照片時才中斷。若依設定或最短間隔略過啟動掃描，也會檢查已載入索引。同一根目錄每次執行最多提醒一次，可選擇稍後處理。
- 按「前往重複掃描」會開啟正確根目錄的「照片品質檢查 → 重複圖片」，並引導手動開始增量掃描。完成後可返回照片牆；既有貼圖中斷後保留照片及重試的流程繼續適用。
- 照片牆、品質與重複清單的大圖預覽，可用滾輪向上放大、向下縮小，縮放時以滑鼠指向的位置定位。保留 50%～400% 滑桿、鍵盤切圖與關閉操作，切換圖片恢復 100%。
- 放大後可按住滑鼠左鍵拖曳平移圖片，方便查看鄰近標籤與細節；放開即停止，切圖、關閉或失焦會清理拖曳狀態。

## 資料安全與限制

- 啟動提醒只讀取 SQLite 中繼資料，不會自動執行全庫重複掃描、讀取原圖、下載雲端佔位檔或儲存待貼圖片。錯誤、取消、離線及已完整的索引不彈提醒。
- 縮放只改變顯示，不修改原圖或照片索引；縮小至可視邊界時，定位受捲動範圍限制。
- 真實 Google Drive／LINE、完整 Windows WebView2 滾輪／左鍵拖曳手感及不同顯示縮放仍需獨立實機驗收。合成資料與自動化測試不代表所有現場環境均已驗收。
