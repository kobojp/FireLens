# FireLens v1.12.0

這份說明對應待發布的開發版本；正式下載仍以 GitHub Releases 實際列出的版本為準。

## 新增功能

- 清冊核對提供獨立全寬表格，可貼上 Excel／Google 試算表的兩欄多列資料、修改儲存格、清空及復原。貼上後先解析預覽，再由使用者確認儲存。
- 清冊管理支援收合及分頁，可設定每頁顯示 5、10 或 20 份清冊。
- 照片瀏覽提供同一設備內的上一張／下一張大圖；未對應照片的快捷歸槽也包含目前類別的選填槽位。
- 多人異常同步顯示當次新增、更新、清除與衝突數量，以及可展開的逐筆設備明細；切換頁面後保留最近結果。
- 品質檢查的月份／批次改為選單，設定頁可按各照片根目錄勾選要排除的第一層資料夾。
- Windows 桌面版加入根目錄「瀏覽…」入口；選擇資料夾只填入路徑，仍需另按「加入」。

## 改善與修正

- 照片瀏覽上方綠色操作提示會在 5 秒後自動收起，連續操作時重新計時。
- 程式確認視窗採一致的置中樣式、鍵盤焦點與 Escape 取消操作；清冊教學預設關閉。
- 清冊名稱重複時阻擋儲存並提示更換名稱；成功儲存後清除已完成的名稱草稿，避免殘留假性重複提示。
- 核對成功後定位至當次有效結果，較舊的請求不會覆蓋後來選取的清冊。
- 重複圖片與品質掃描的操作按鈕更清楚，並保留手動掃描及忙碌狀態防護；本機歷史備份預設收合。
- 修正已使用較新資料庫設定時的原始碼啟動相容性。PowerShell 啟動失敗會保留錯誤紀錄及非零退出碼，互動視窗等待 Enter 後才關閉。

## 資料安全與相容性

- 資料庫升級保留既有根目錄的排除設定，新加入的根目錄獨立設定；排除不刪除實體資料夾或照片。
- 多人異常同步逐設備合併，不整份覆蓋 SQLite。同一設備的分歧需人工選擇，備份復原先預覽影響再確認。
- 動態類別的共享事件採新版格式，參與同一共享目錄的電腦應一併升級；舊程式可能安全拒絕未知格式。
- 原始照片不因品質掃描、設定變更或異常同步被改名、刪除或重新編碼。選填照片槽位不計入必填缺照。
- 「本機已讀取」不表示 Google Drive 已上傳完成或其他電腦已收到；匯出提供本機資料時間與同步狀態供核對。

## 安裝與更新

- 正式發布後提供繁體中文安裝精靈與免安裝 EXE；原始碼使用者可在目前專案目錄執行 `run-desktop.ps1`。
- 線上更新仍須通過內建公鑰驗章、檔案雜湊與打包程式自我測試，失敗時保留回滾流程。
- 本版已通過合成資料、自動化測試、Windows EXE／安裝包及更新器故障情境驗證；這些結果不代表已在每種現場環境驗收。

## 已知限制與待驗收

- 真實雙機 Google Drive 傳輸、ACL、離線與衝突，以及真實 Google OAuth／私人試算表操作仍需獨立驗收。
- 真實 LINE／Google Sheets 剪貼簿、Windows 原生資料夾選擇、照片歸槽，以及完整深淺色／不同縮放與窄視窗矩陣仍有待辦；本機部分畫面與 DOM 測試不代替完整實機操作。
- 模糊判讀仍是候選初篩，現場設備照片需要授權副本校準，不能視為自動合格判定。
- 共享事件自動封存保留政策與 Google Sheets 批次寫入尚未定案，本版不新增這些操作。
